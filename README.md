# oxygen Deobfuscator

Static **LuaObfuscator** deobfuscator.

Supports:
- Chaotic Good
- Chaotic Evil
- Obfuscate v1
  
## Usage

```bash
node index.js <file.lua>
```

```bash
node index.js script.lua --out clean.lua
```

Result goes to `output/<file>/reconstructed.lua` if you don’t pass `--out`.
